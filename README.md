Projeto desenvolvido para auxiliar na organização de eventos e cafés da manhã da igreja, com foco em gerenciamento de informações, organização de participantes e estruturação de dados.

## Objetivo
Criar uma solução digital para facilitar a organização de eventos internos, utilizando desenvolvimento web e banco de dados para melhorar a administração e planejamento.

## Tecnologias Utilizadas
- HTML
- CSS
- Banco de Dados

## Funcionalidades
- Cadastro e organização de participantes
- Gerenciamento de informações para eventos
- Estrutura de banco de dados para melhor controle
- Interface simples e funcional
- Planejamento digital para café da manhã comunitário

## Aprendizados
Este projeto contribuiu para o desenvolvimento de habilidades em:
- Estruturação de sistemas web
- Banco de dados
- Organização de informações
- Desenvolvimento prático de soluções reais

## Status
Projeto concluído como prática de desenvolvimento e aplicação de tecnologia em um contexto comunitário.
